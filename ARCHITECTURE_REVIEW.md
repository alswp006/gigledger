# Architecture Review
Generated: 2026-10-09T18:04:20.808Z
Score: 58/100

## Summary
The codebase has a sound layered shape (pages, components, hooks, lib) with a clear storage/calc/format separation and well-documented intent. However, it carries visible residue from parallel, packet-based generation: duplicated components (SubmitFooter, EmptyState), a duplicated haptic helper in six files, two competing domain models (contract.ts vs types.ts), and inconsistent state access (useLedger vs direct storage calls). These should be consolidated before the structure drifts further.

## Issues
