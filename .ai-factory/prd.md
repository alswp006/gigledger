# GigLedger

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
배달·대리운전·쿠팡플렉스 등 여러 플랫폼 수입을 매일 기록해 한 곳에서 합산 관리

## Problem
긱워커·N잡러는 수입원이 여러 플랫폼에 흩어져 있어 이번 달 총수입과 실질 시급을 파악하기 어려움

## Target Users
배달앱·대리운전·쿠팡플렉스·크몽 등 복수 플랫폼에서 일하는 20-40대 긱워커, N잡러

## Core Features
1. 플랫폼별 일일 수입 수동 입력
2. 주간/월간 합산 수입 대시보드
3. 플랫폼별 실질 시급 계산
4. 연속 기록 스트릭 및 목표 수입 달성률
5. 리워드 광고 시청 후 월간 소득 리포트 공개
6. 수입 변동 그래프 공유 카드

## Monetization
- Model: ads
- Estimated MRR: $220-280
- Reasoning: 매일 수입을 입력하는 습관형 앱으로 DAU가 안정적으로 확보되며, 월간 리포트를 리워드 광고 뒤에 배치해 높은 전환율 기대
